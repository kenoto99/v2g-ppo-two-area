# Reproduction guide

Everything in the manuscript (numbers, tables, figures) is generated by the scripts
in this repository from the raw simulation records in `results/`. Nothing is edited by hand.

## Environment

See `results/ENVIRONMENT.txt` for the exact versions used for the reported results
(Python 3.13, NumPy 2.4.6, SciPy 1.18.1, PyTorch 2.15.0, Gymnasium 1.4.0,
Stable-Baselines3 2.9.2, pandapower 3.5.6, numba 0.68.1, matplotlib 3.11.2).
Install with

```bash
pip install -r requirements.txt
```

The simulation model version is `ENV_VERSION = "v3"` in `v2g/env.py`; every trained policy
records it in `results/ppo_*/meta.json`.

## Random seeds

| Stream | Seed |
|---|---|
| PPO training seeds (main) | 0, 1, 2, 3, 4 |
| Ablation / sensitivity / squashed-policy seeds | 0, 1, 2 (sensitivity: 0, 1) |
| Training-day generator | `default_rng(1000 * seed + env_index)`, 4 parallel environments |
| Validation days (10, model selection) | `default_rng(10000)` |
| Test days (30) | `default_rng(2026)` |
| Stress days (20) | `default_rng(777)` |
| Hourly disturbance of each day | `default_rng([scenario_seed, hour])` (identical for every controller) |
| Power-flow verification cases | `default_rng(0)` |

## Commands (in order)

```bash
python scripts/validate_models.py                 # power flow vs pandapower, LFC closed-form checks
python -m pytest -q tests/                        # physics and bookkeeping tests (or: python tests/test_physics.py)
bash scripts/run_queue_v3.sh                      # all training runs (about 4 h on 2 CPU cores)
python scripts/evaluate_all.py UC RB DAO PPO ABL  # test / stress / validation evaluation of every controller
python scripts/raw_clip_breakdown.py              # per-dimension raw-action saturation of the final policies
python scripts/evaluate_modes.py decomposed none window hour fullhour   # regulation-energy treatments
python scripts/fig_system.py                      # feeder and profile figures
python scripts/make_results.py                    # every table, figure and number macro
python scripts/verify_all.py ../manuscript        # independent recomputation and PASS/FAIL report
python scripts/make_checksums.py ../manuscript    # SHA-256 of all final outputs
```

The manuscript is built with `../manuscript/build.sh` (copies tables, macros and figures from
this repository, then runs pdflatex twice). The verification report is `results/verification_report.md`
and the checksums are `results/CHECKSUMS.sha256`.

## Individual training run

```bash
python scripts/train_ppo.py --seed 0 --steps 400000 --tag main
python scripts/train_ppo.py --seed 0 --steps 200000 --tag noF --cfg '{"w_f":0.0,"w_tie":0.0}'
python scripts/train_ppo.py --seed 0 --steps 200000 --tag squash --squash
```

Training is deterministic for a given seed on the same CPU and library versions
(PyTorch single-threaded). Different hardware or library versions can change the
learned policy slightly; the evaluation scripts, the tables and the verification suite
will then reflect the new policy, and `verify_all.py` recomputes every number in the
manuscript from the new raw results.
