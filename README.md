# Two-time-scale V2G voltage support and frequency reserve (PPO)

Code and data for the manuscript "Two-Time-Scale Coordination of Vehicle-to-Grid
Voltage Support and Frequency Reserve in a Two-Area System Using Proximal Policy
Optimization".

## Contents

| Path | Purpose |
|---|---|
| `v2g/feeder.py` | IEEE 33-bus feeder (pandapower `case33bw` data), BIBC/BCBV backward/forward sweep |
| `v2g/lfc.py` | Two-area LFC model (inertia, damping, governor, turbine, tie line, ACE/AGC, saturated V2G droop), RK4, numba |
| `v2g/profiles.py` | Daily load, PV and plug-in availability profiles; scenario generator (train / val / test / stress) |
| `v2g/env.py` | Gymnasium environment: hourly slow layer + 60 s fast layer, reward, constraints |
| `v2g/controllers.py` | Benchmarks: uncontrolled charging (UC), rule-based (RB), day-ahead optimisation (DAO) |
| `v2g/evaluate.py` | Roll-outs and daily metrics |
| `scripts/validate_models.py` | Verification against pandapower and closed-form LFC values -> `results/validation.json` |
| `scripts/train_ppo.py` | PPO training (Stable-Baselines3), validation-based model selection |
| `scripts/run_queue.sh` | All training runs used in the paper (5 seeds + reward ablation) |
| `scripts/evaluate_all.py` | Evaluates all controllers on validation, test (30) and stress (20) days |
| `scripts/make_results.py` | Builds every table, figure and number macro in the manuscript |
| `scripts/fig_system.py` | Feeder and profile figures |
| `results/` | Learning curves, trained policies (`ppo_*/best_model.zip`), evaluation records |

## Reproduce

```bash
pip install -r requirements.txt
python scripts/validate_models.py
bash scripts/run_queue.sh                 # about 3 h on 2 CPU cores
python scripts/evaluate_all.py UC RB DAO PPO ABL
python scripts/fig_system.py
python scripts/make_results.py            # tables in results/tex, figures in figures/
```

All random streams are seeded: training seeds 0 to 4, validation days
`default_rng(10000)`, test days `default_rng(2026)`, stress days `default_rng(777)`,
and every hourly disturbance is seeded by (scenario seed, hour), so all controllers
see identical disturbances.

## Manuscript

`manuscript/` holds the LaTeX source of the manuscript and the supplementary material; `manuscript/build.sh`
regenerates the PDF from the tables, macros and figures produced by `scripts/make_results.py`.

## Verification and checksums

`python scripts/verify_all.py ../manuscript` recomputes every number in the manuscript from the raw records in
`results/` and writes `results/verification_report.md`. `results/CHECKSUMS.sha256` lists the SHA-256 of every
raw result, trained policy, table, figure and PDF, and `results/ENVIRONMENT.txt` the exact package versions.
Per-day evaluation traces of the validation and stress sets and the cached DAO plans are omitted from the
repository for size; they are regenerated by `scripts/evaluate_all.py` and `scripts/evaluate_modes.py`.
